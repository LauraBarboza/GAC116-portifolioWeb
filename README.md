# Página Pessoal — Laura Costa Sarto Barboza

Atividade Prática 2 da disciplina **GAC116 — Programação Web**, Universidade Federal de Lavras (UFLA).

O projeto contém duas versões equivalentes do mesmo portfólio:

- `bootstrap/`: versão com **Bootstrap 5.3.3**;
- `bulma/`: versão com **Bulma 1.0.2**.

## Recursos implementados

- HTML, CSS e JavaScript;
- layout responsivo;
- navegação por seções;
- tema claro e tema escuro;
- preferência de tema salva no `localStorage`;
- informações reais da estudante;
- foto de perfil;
- seções de apresentação, habilidades, projetos, experiência e contato;
- página inicial para escolher entre as duas versões.

## Estrutura

```text
portifolioWeb/

│   └── assets/
│       ├── css/styles.css

│       └── img/perfil.jpg
├── bulma/
│   ├── index.html
│   └── assets/
│       ├── css/styles.css
│       ├── js/script.js
│       └── img/perfil.jpg
├── index.html
├── README.md
└── LICENSE
```

## Executar localmente

Basta abrir o arquivo `index.html` da raiz em um navegador.

Também é possível utilizar a extensão **Live Server** do VS Code.
